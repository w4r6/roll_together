# Roll Together privacy policy

Roll Together sends only the information required to synchronize a temporary watch room.

## Data processed

- Playback state: playing or paused
- Current video timestamp in seconds
- A randomly generated room identifier
- A randomly assigned or user-chosen room username
- Connection metadata normally processed by internet services, such as IP address, browser origin, and connection timing

The application does not maintain accounts, analytics profiles, or a permanent room database. Room state is held in server memory and is removed after the last viewer leaves or the service restarts. Operational infrastructure may retain limited request or connection logs according to the hosting provider's policies.

The username preference is stored with the browser's synchronized extension storage. Depending on browser settings, the browser vendor may synchronize it between the user's signed-in browsers.

Invite links contain the room identifier. Anyone with a valid invite link can participate in that room, so users should share links only with the intended viewers.

Roll Together does not sell data or share it for advertising.
